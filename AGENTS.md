# Правила для тех, кто правит код

Короткая памятка для людей и AI-ассистентов. Подробности — по ссылкам.

- **Код** — сначала [docs/CORE.md](docs/CORE.md): что можно менять свободно, а что
  держит весь сайт. Файл с пометкой `⚠ КАРКАС` или `⚠ КОНТРАКТ` в шапке правьте
  только после того, как прочитали указанный в ней раздел.
- **Факты, статьи, связи** — [docs/AI-CONTRIBUTING.md](docs/AI-CONTRIBUTING.md).
- **Устройство проекта** — [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

## Нельзя без осознанного решения

- Прыгать по шкале вдоль времени мимо `jumpToGroup` (`src/components/TimelineSection.tsx`).
- Делать элемент шкалы только для одной ориентации.
- Импортировать `src/data/content.ts` статически где-либо, кроме `ModalHost.tsx`.
- Переименовывать параметры ссылок, ключи `localStorage` и id объектов, менять
  формат файлов `@1` без совместимости со старым.
- Менять `base` в `vite.config.ts`, править `src/data/items/reference.json` руками.
- Удалять, пропускать или ослаблять тесты, чтобы CI стал зелёным.

## Перед коммитом

```bash
npm run lint && npm test && npm run build && npm run test:e2e
```

Изменения на шкале проверяйте и глазами: обе ориентации, тёмная тема, телефон.
