# Синхрония — атлас параллельной истории

Интерактивная **синхронная хронология**: события и деятели восьми стран на одной вертикальной
шкале времени — от первого года нашей эры до наших дней. Главная идея сайта не в списке дат,
а в одновременности: одна строка показывает, что происходило в разных странах в один и тот же год.

> Пока Германия печатает первые книги, Полоцк отправляет Скорину в Прагу; пока Париж строит
> республику, Речь Посполитая исчезает с карты; пока Берлин делит стену, над Землёй летит
> первый человек.

## Что уже есть

- **8 исторических линий:** Германия, Англия · Британия, Франция, Россия, Беларусь, Испания,
  Китай, Япония — свыше 200 объектов, покрывающих все эпохи от античности до современности.
- **Две темы оформления:** «Пергамент» (по умолчанию) и «Ночной атлас». Выбор сохраняется.
- **Не больше шести колонок** на экране. Когда включено больше линий, близкие страны
  «вклиниваются» в общую дорожку: в колонке рисуются две шкалы, а событие различается
  цветом точки и бейджем страны на карточке.
- **Липкая шапка стран** и липкая колонка дат: горизонтальная прокрутка шапки и тела таблицы
  синхронна по построению — они лежат в одном контейнере прокрутки.
- **Перетаскивание поля мышью** по обеим осям с инерцией; клик после перетаскивания подавляется.
- **Масштаб 65–120 %** ползунком плюс кнопка «уместить», подбирающая масштаб под число колонок.
- **Скрытие и возврат стран,** режим «только эта страна», кнопка «показать все».
  Последнюю страну скрыть нельзя.
- **Слои** «всё / события / деятели», фильтр «только вехи», фильтр по эпохе, фильтр по темам
  и полнотекстовый поиск с подсветкой совпадений.
- **Полный текст в модальном окне.** Значок в углу карточки открывает статью, свёрстанную
  из Markdown: заголовки, списки, цитаты, таблицы, ссылки, разделители. Внутри — теги
  и переход к соседним объектам той же линии.
- **Конструктор персоналий:** готовые карточки в один клик и форма для своего объекта.
  Добавленное сохраняется в браузере, страна автоматически становится видимой,
  карточка подсвечивается, поле прокручивается к ней.
- **Доступность:** карточки — настоящие кнопки, навигация стрелками, видимый фокус, тип объекта
  читается не только цветом (◆ событие / ✦ деятель, круглый и ромбический узел), учитывается
  `prefers-reduced-motion`.

## Структура проекта

```text
src/
  App.tsx                     сборка экранов, ничего кроме композиции
  types.ts                    доменная модель
  data/
    countries.ts              справочник стран: подписи, пояснения, цвета
    columns.ts                раскладка стран по колонкам и правила объединения пар
    eras.ts                   эпохи для лент-разделителей и быстрых переходов
    timelineItems.ts          агрегатор всех объектов + список тем
    articles.ts               развёрнутые статьи в Markdown
    suggestedPeople.ts        заготовки для конструктора персоналий
    items/                    по одному файлу на страну
      germany.ts england.ts france.ts russia.ts
      belarus.ts spain.ts china.ts japan.ts
  lib/
    format.ts                 даты, склонения, ключ сортировки
    timeline.ts               фильтрация, группировка, поиск ближайшего объекта
    markdown.ts               сборка статьи из полей карточки
    useTimelineState.ts       всё состояние приложения в одном хуке
    usePanning.ts             перетаскивание поля мышью
    usePersistentState.ts     состояние, переживающее перезагрузку
  components/                 по компоненту и файлу стилей на блок
  styles/
    tokens.css                дизайн-токены и темы
    base.css                  сброс, типографика, общие примитивы
```

Разделение сознательное: компоненты не знают, откуда берутся данные, а логика не знает,
как они выглядят. Массив `timelineItems` можно заменить загрузкой из JSON, CMS или API,
не трогая интерфейс.

## Как добавить данные

**Новый объект в существующую страну** — одна запись в `src/data/items/<страна>.ts`:

```ts
{
  id: 'de-worms-1122',
  country: 'germany',
  year: 1122,
  kind: 'event',            // 'event' — что произошло, 'person' — через кого понять эпоху
  title: 'Вормсский конкордат',
  summary: 'Одно предложение: что произошло.',
  detail: 'Два-четыре предложения: что, почему важно и как связано с соседями.',
  tags: ['церковь', 'право'],
  importance: 2,            // 3 — опорная веха эпохи, 2 — заметное, 1 — контекст
}
```

Для персоналий добавляется `life`, для процессов — `endYear`, для точных дат — `month` и `day`.

**Новая страна** — новый файл в `src/data/items/`, одна строка в `src/data/timelineItems.ts`
и одна запись в `src/data/countries.ts`. Больше ничего менять не нужно: ширина таблицы,
переключатели и цвета считаются от справочника.

**Развёрнутая статья** — запись в `src/data/articles.ts` по идентификатору объекта.
Поддерживается полный Markdown с расширениями GFM: заголовки, списки, цитаты, таблицы,
ссылки, зачёркивание, разделители, код. Если статьи нет, документ собирается автоматически
из полей карточки — модалка всё равно открывается осмысленной.

## Колонки и парные линии

Колонок на экране не больше шести — это предел, при котором карточка ещё читается
(на колонку остаётся около 250 px). Когда включено больше стран, близкие линии
объединяются в общую дорожку по списку из `src/data/columns.ts`:

```ts
export const columnPairs: [CountryId, CountryId][] = [
  ['russia', 'belarus'],
  ['china', 'japan'],
  ['germany', 'spain'],
  ['england', 'france'],
];
```

Пары подключаются сверху вниз, пока число колонок не станет допустимым: восемь линий
дают шесть колонок, две из которых общие. В такой колонке рисуются две вертикальные шкалы,
узел карточки садится на шкалу своей страны, а на карточке появляется бейдж с её кодом.
Как только лишнюю страну скрывают, пара автоматически распадается на отдельные колонки.

## Задел на месяцы и дни

Модель данных уже описана «с запасом»: у объекта есть необязательные `month` и `day`,
часть событий их уже хранит и показывает точную дату («14 июля 1789», «9 ноября 1989»).
Группировка вынесена в функцию с параметром уровня детализации:

```ts
buildGroups(items, countries, 'year')   // сейчас
buildGroups(items, countries, 'month')  // строка года дробится на месяцы
buildGroups(items, countries, 'day')    // и дальше на дни
```

Ключи групп (`'1789'`, `'1789-07'`, `'1789-07-14'`) и сортировка через `timeKey`
уже рассчитаны на все три уровня, поэтому переход к делению года на месяцы и дни
не потребует миграции данных — нужен только переключатель детализации в интерфейсе.

## Производительность

Фильтрация, сортировка и группировка мемоизированы; строки и карточки обёрнуты в `React.memo`,
поэтому перерисовывается только то, что изменилось. Синхронизация горизонтальной прокрутки
не требует JavaScript — шапка и тело таблицы находятся в одном скролл-контейнере.
Структура строк независима друг от друга, так что при дальнейшем росте базы
на это место встанет виртуализация без переделки разметки.

## Стек

React 19 · TypeScript · Vite · Framer Motion · react-markdown с remark-gfm ·
CSS Custom Properties. Шрифты (Lora, Inter, JetBrains Mono) подключены пакетами,
а не через CDN, поэтому сайт не зависит от внешней сети. Модальное окно вместе
с разбором Markdown грузится отдельным чанком — только при первом открытии статьи.

## Оговорка о границах

Границы стран менялись. Ранние события привязаны не к современным государствам
в строгом смысле, а к территориям, политическим традициям и культурным линиям,
из которых позже выросли нынешние страны. Пояснение к каждой колонке есть
в интерфейсе и в `src/data/countries.ts`.
